# FAQ

## What is yc-pitch-deck-max?
Super-skill for startup pitch decks. 12 slides, 30+ styles, PPTX/HTML/Marp output.

## How do I install it?
```bash
git clone https://github.com/josezuma/yc-pitch-deck-max.git
cd yc-pitch-deck-max
python3 scripts/generate.py --help
```

## Do I need any external dependencies?
No. All scripts use Python stdlib only.
